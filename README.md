# FameEx_Python_Testing

# 项目说明文档

本项目用于自动化测试合约与现货交易流程、合约经济人相关数据，包含测试用例、执行入口、配置文件及测试报告等模块。

## 项目结构
``` toml
.
├── api/     存放请求接口方法，用例层调用
├── common/  存放项目中使用的通用函数、工具类（如封装的请求方法、数据库操作等）
├── config/  存放各类配置文件，如测试环境地址、账号、密钥等
├── report/  存放测试执行后自动生成的测试报告
├── tests
│   ├── contract_spot/  存放合约与现货交易全流程的功能测试用例
│   ├── exchange_broker/  存放合约经济人数据相关的测试用例
│   ├── old_contract_spot/  存放合约与现货交易全流程的功能测试用例（已弃用）
├── run_test.py  入口脚本，用于加载并执行合约与现货流程的测试用例
├── run_test_ex.py  入口脚本，用于加载并执行合约经济人相关的测试用例
```

## 使用说明

### 安装依赖

请确保已安装必要的 Python 包，可以通过如下命令安装：

``` bash
pip install -r requirements.txt

```


### 执行合约与现货流程测试用例

``` bash
python run_test.py
```

### 执行合约经济人相关测试用例

``` bash
python run_test_ex.py
```

# 测试报告
测试完成后会自动生成报告文件，存放在 report/ 目录下，可直接通过浏览器打开查看。
